# Security Policy

Mixion runs entirely in the browser. Videos and scans are processed locally and never leave the user's device.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/shunyakoide/mixion/security/advisories/new), not in a public issue.

Include the steps to reproduce, the browser and version, and the impact you expect. You should get a reply within a week.

## Supported versions

Only the latest `main`, deployed at https://shunyakoide.github.io/mixion/, receives fixes.
