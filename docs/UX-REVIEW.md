# Mixion UX レビュー（2026-09-05）

対象: 現行 UI（Print / Draw / Scan+Animate）。UI/UX ガイドライン DB（ui-ux-pro-max）の優先度表と、実画面のスクリーンショットをもとに整理。

## 結論

機能は揃っているが、「今どこにいて、次に何をすればいいか」と「最初に何を入れればいいか」が画面から読み取れない。直すべきは見た目ではなく **導線** で、次の 3 点に集約される。

1. ステップ表示が「ラベルの列」でしかなく、進捗・完了・次の行動を示していない
2. 最初の画面で主役であるべき「動画を入れる」が、右のプレビュー枠より小さく弱い
3. 各ステップの終わりに「次へ」がなく、完了状態からの行き先が示されない

## 提案

### A. ステップナビゲーションを「進捗バー付きのステッパー」にする（問題 1, 4, 5, 9 に対応）

- 4 ステップを番号付きの大きめのタブにし、状態を 3 種で示す: 完了（チェック）、現在（塗り）、未着手（枠のみ）
- 各ステップの完了条件をアプリが判定して表示する
  - Print: PDF を保存した
  - Draw: ユーザーが「印刷して描いた」にチェックした（アプリは検知できないので自己申告）
  - Scan: 1 ページ以上 Apply した
  - Animate: 書き出した
- 各画面の下端に固定の「次へ」バー（前へ / 次へ + いま何が足りないかの一言）を置く。次に進めない理由（例: 「動画を読み込むと PDF を作れます」）をボタンの横に出す
- Animate を独立した画面にする。Scan 画面には四隅指定と Apply だけを残し、Animate に再生・補完・書き出しをまとめる

### B. Print の最初の画面を「動画を入れる」一点に絞る（問題 2, 3）

- 動画未読込のときは、プレビュー枠を出さずにドロップ領域を画面中央に大きく置く（高さ 300px 以上、アイコン + 「動画をここにドロップ」+ 「ファイルを選ぶ」ボタン）
- ドロップ領域の下に 1 行で流れを説明する: 「動画をフレームに分けて A4 に並べた PDF を作ります。印刷して描き、スキャンすると動画に戻せます」
- 読み込み後に初めて 2 カラム（設定 + プレビュー）に切り替える
- ドラッグ中はページ全体をドロップ可能にし、オーバーレイで「ここに離す」を出す（領域の内側に正確に落とす必要をなくす）

### C. Scan の空状態と手順を明示する（問題 6, 7, 8）

- 空状態: 中央に大きなドロップ領域「スキャンした画像（JPEG / PNG、1 ページ 1 ファイル）をここに」+ 3 行の手順（取り込む → 四隅を押す → Apply）
- 四隅指定: キャンバス上に「次は 右上 のマーカー」を大きく表示し、指定済みの隅は番号付きでチェック。4 点そろったら Apply ボタンを強調（色を変える）
- リストの各行に進捗を示す小さな進捗（0/4 → 4/4 → 済）
- 全ページ Apply 済みになったら、画面上部に「40 / 40 フレームが揃いました → Animate へ」のバナーを出す

### D. 小さな整え（問題 10〜12）

- 矢印・再生・ページ送りを Lucide の SVG アイコンに置き換える
- チップ・ステップ・ボタンに `focus-visible` のリングを付ける
- FrameStrip とスキャン一覧の状態色に凡例を 1 行付ける
- カスタム fps は入力欄を選択状態と同じ見た目（黒枠 + 「12 fps」表示）にする

### 見た目の方向性（任意）

DB の推奨は「Exaggerated Minimalism（余白多め・高コントラスト・大きめの見出し）、Archivo / Space Grotesk、Document grey + Scan blue のアクセント」。今の白黒基調と相性がよく、主 CTA と「次へ」だけを青（#2563EB 系）にすると導線が浮き上がる。フォントは任意で、導線の改善を優先する。

## 実装順（提案）

1. A のステッパー + 「次へ」バー + Animate 画面の分離（骨格が変わるので最初）
2. B の Print 初期画面
3. C の Scan 空状態と四隅指定のガイド
4. D の整え

1〜3 で「どう進めばいいか」「何を入れればいいか」は解決する。所要はそれぞれ半日程度。

## 実施状況（2026-09-05）

- A: 実施。Draw ステップは廃止して 3 ステップ（Print / Scan / Animate）にし、番号 + 完了チェックのステッパー、下端固定の「前へ / 次へ」バー（足りないものの一言つき）、Animate を独立画面に分離。Draw の注意書きは PDF 保存後のパネルと Scan の空状態（折りたたみ）へ移動
- B: 実施。動画未読込時はドロップ領域だけを中央に大きく置き、1 行の説明を添えた。ドラッグ中はページ全体がドロップ先になる
- C: 実施。Scan の空状態（大きなドロップ領域 + 3 手順 + 注意書き + 手入力）、キャンバス上の「次は 右上 の ■」バナー、Apply の文言、全フレーム揃ったときのバナー
- D: 実施。SVG アイコン、focus-visible リング、状態色の凡例、カスタム fps の選択表示、IBM Plex Sans / Plex Sans JP、色トークン（paper / ink / rule / accent / ok / warn / danger）
- 追加（2026-09-06）: 色つきの四角を並べる FrameStrip は意味が伝わらなかったので廃止。Animate は全コマのサムネイル一覧（番号つき、補完・流用したコマは枠色で区別、クリックで Player がそのコマで停止）、Scan は「切り出したコマ n / N」のバーと未取得ページの列挙に置き換えた
- 未実施: モバイル幅の確認、Safari
